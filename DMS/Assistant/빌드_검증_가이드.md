## GdsMapControl 빌드

```powershell
& 'C:\Program Files\Microsoft Visual Studio\2022\Professional\MSBuild\Current\Bin\MSBuild.exe' `
```

- OpenTK / GLControl / Oracle HintPath는 현재 `..\..\00_Solution\DACrux2015wc_ChippacPOC\packages\...`를 가리킨다(DMS 이동 후 미커밋 변경). 해당 폴더에 3개 패키지가 있다. 루트 `GdsMapControl`은 예전 `..\packages` 경로를 유지한다.
- 실행 중인 GDS 뷰어 / DACrux가 EXE를 잡고 있으면 빌드가 실패한다. 프로그램을 종료하거나 OutDir를 분리한다. OutDir만 바꾸고 HintPath가 풀리지 않으면 `CS0246 (Vector2, GLControl)`이 난다. 이때 3개 DLL을 OutDir에 먼저 복사한다.
- non-SDK 프로젝트다. 새 `.cs` 파일은 csproj에 `<Compile Include>`를 직접 추가해야 빌드에 포함된다.
- C# 7.3 문법 범위를 지킨다.
- 과거 빌드 결과: 경고 CS0649(`GlDefectItem.LineVertexCount`) 1건 (2026-09-30 루트 폴더 기준 / 과거 기록).

## 자주 겪은 문제

- 관리자 권한 Visual Studio가 `DACrux.TEST.ENGUI.csproj` 등을 열고 있으면 csproj 수정이 `EPERM`으로 실패한다. 사용자에게 VS의 Reload 안내를 닫거나 VS 종료를 요청한다.
- 솔루션 / ENGUI csproj / `MenuFile.mnu`는 여러 기능이 함께 수정한다. 편집 직전에 다시 읽고 다른 기능의 항목을 보존한다.
- 메뉴 추가는 `01_WinApp/DACruxV5/MenuFile.mnu`와 실행용 `100_ClientBin/MenuFile.mnu` 두 곳이다. 2026-10-02 기준 아래 4개 메뉴는 두 파일 모두에 있다.
