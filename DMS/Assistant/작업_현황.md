## 현재 진행 단계 해석

```text
GDS Viewer / Chain 메모리 편집
 -> PLACED 배치 형식 v2와 Scene 변환
 -> DB 스키마 생성 기록
 -> 개정본 헤더 서비스 코드 작성       <- 현재 소스에서 확인한 서비스 범위
 -> Layer / Source / Placed 대량 저장   <- 후속 연계 필요
 -> Chain Version 저장 / DB 단독 복원  <- 후속 연계 필요
 -> AOI / E-Test Correlation 통합      <- 좌표 / 매핑 기준 확인 필요
```

파일 Map 원형 생성과 KLARF 파일 조회는 별도 기능 작업이다. 위 순서가 모든 기능의 실제 작업 순서나 사용자 우선순위를 의미하지 않는다.
