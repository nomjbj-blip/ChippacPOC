# YYYY-MM-DD 작업 이력

아래 항목을 작업 단위마다 복사해 당일 변경 이력 끝에 추가한다. 같은 파일을 다른 도구가 갱신했다면 먼저 다시 읽고 합친다.

## 작업 ID / 기능 / 짧은 제목

- 시각: YYYY-MM-DD HH:mm KST
- 담당: Claude / Codex / 사용자 확인
- 상태: 진행 중 / 부분 완료 / 검증 대기 / 완료 / 중단
- 목적과 사용자 요청:
- 수정 파일 / 주요 함수:
- 변경한 동작과 이유:
- 결정 사항 / 근거 문서:
- 검증 명령 / EXE / 샘플:
- 실제 결과 / 로그:
- 미실행 / 미확인 항목:
- 남은 오류 / 중단 이유:
- 다음 작업 한 단계:
- 갱신한 기능 문서 / 작업 현황:

비밀번호 / 접속 문자열 / 고객 원시 데이터는 붙여 넣지 않는다. 결과를 확인하지 않은 작업은 완료로 적지 않는다.
