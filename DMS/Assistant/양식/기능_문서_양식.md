# F번호 / 기능 이름

최종 갱신: YYYY-MM-DD HH:mm KST / 작성 도구: Claude 또는 Codex
상태: 설계 / 소스 확인 / 구현 중 / 검증 대기 / 확인 완료 중 실제 상태

## 목적

사용자가 어떤 작업을 하기 위한 기능인지 적는다.

## 파일과 호출 흐름

파일 링크 / 클래스 / 주요 함수 / 소속 프로젝트 / 호출 순서를 적는다.

## 현재 구현과 중요한 로직

구현된 동작, 입력과 출력, 좌표 / 키 / 상태 / 예외 처리와 그 이유를 적는다.

## 설계만 된 부분과 미완료

현재 소스와 구분해서 적는다. 다른 기능 또는 고객 확인이 필요한 부분을 적는다.

## 검증

확인 날짜 / 대상 소스 또는 EXE / 샘플 / 명령 / 결과 / 로그 경로를 적는다. 빌드 / Probe / 화면 / DB 검증을 구분한다. 실행하지 않은 명령은 예시로 표시한다.

## 다음 단계

바로 이어서 할 작은 작업 하나와 완료 기준을 적는다. 관련 작업 현황과 당일 이력을 연결한다.
