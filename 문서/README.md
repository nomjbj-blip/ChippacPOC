# 문서 폴더 안내

md(작업하며 쓰고 고치는 문서)는 `설계/`, 그 밖의 파일(받거나 만들어 전달하는 파일)은 `자료/`에 둔다.

## 설계 (md)

| 폴더 | 내용 |
|---|---|
| `설계/01_계획_관리` | 인수인계 분석, 문서 검토, 역할 범위(RnR) |
| `설계/02_GDS` | GDS 파싱, Chain, GDS Map 저장 / 조회, 반전, Label 검색, 대표 Device |
| `설계/03_KLARF_Map` | KLARF 업로드, Wafer Map Setup / 조회, 파일간 기준정보, Die 좌표 대응 |
| `설계/04_ETest` | E-Test 파싱, Limit / Para Spec, Upload, YMS 적재 / 연계 |
| `설계/05_연관분석` | GDS x KLARF x E-Test 연관 분석 화면 |
| `설계/06_환경_운영` | 빌드 / 배포 / 설치 / License, DB 환경, 소스 정리 점검 |

## 자료 (md 외)

| 폴더 | 내용 |
|---|---|
| `자료/01_고객자료` | 제안서, AOI-ET 자료, Function List, GDS TABLE, 캡처 |
| `자료/02_계획_일정` | WBS, 개발일정, 개발내역 엑셀, 붙여넣기용 txt |
| `자료/04_시스템_개발자료` | 테이블 명세서 (POC / Common / DMS / YMS) 등 시스템 개발 자료 |
| `자료/03_발표자료` | 설명 / 리뷰용 PPT / PPT 에 넣는 그림(날짜 하위 폴더, 예: `2026-10-16_대표이미지`) |

## 새 문서 규칙

- 파일 이름은 기존처럼 `YYYY-MM-DD_주제_종류.md` 로 짓는다.
- md 는 주제에 맞는 `설계/` 하위 폴더, pptx / xlsx / pdf / txt 는 용도에 맞는 `자료/` 하위 폴더에 둔다.
- 예외: claude.ai 채팅에 올리는 자료 묶음은 md 와 샘플(tsv / txt)을 한 폴더에 둔다. `설계/01_계획_관리/YYYY-MM-DD_Claude채팅_분석자료/` (2026-10-22)
- 맞는 폴더가 없으면 새 폴더를 만들지 말고 가장 가까운 폴더에 두고 이 표에 적는다.
- 소스 주석과 Assistant 문서에서는 `문서/설계/02_GDS/파일명.md` 처럼 하위 폴더까지 적는다.
