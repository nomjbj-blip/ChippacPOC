## 6. 주의

- 실제 앱 DB 에는 로컬에 없는 Table 이 더 있을 수 있다. 예: TQD_ALARM_SETUP / TQD_ALARM_USER / TQD_ALARM_DATA (KLARF 자동 적재 알람, 꺼진 서비스만 씀). 7절 SQL 결과에서 이 문서에 없는 Table 은 따로 판정한다.
- TD_* 는 E-Test 저장 때 새로 생기고, 데이터가 비면 앱이 지운다. 직접 지우지 않는다.
- 판정은 소스 기준이다. 배포된 DLL 이 소스와 다르면 결과가 달라질 수 있다.
- 숨긴 메뉴(Admin 등)를 다시 열면 B 묶음 Table 이 다시 필요하다.
- 지울 때는 Export 로 백업한 뒤 지우고, 지운 목록을 변경 이력에 남긴다.

## 7. 실제 앱 DB 비교용 SQL (조회만)

앱 소유 계정으로 실행한다.

```sql
SELECT T.TABLE_NAME, T.NUM_ROWS, T.LAST_ANALYZED,
       ROUND(NVL(S.BYTES, 0) / 1024 / 1024, 1) AS SIZE_MB
  FROM USER_TABLES T
  LEFT JOIN (SELECT SEGMENT_NAME, SUM(BYTES) AS BYTES FROM USER_SEGMENTS WHERE SEGMENT_TYPE LIKE 'TABLE%' GROUP BY SEGMENT_NAME) S
    ON S.SEGMENT_NAME = T.TABLE_NAME
 ORDER BY T.TABLE_NAME;
```
