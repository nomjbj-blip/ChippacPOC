| 드롭다운처럼 쓰는 버튼 | 글자 끝에 `▼`, 아이콘 FILTER, 왼쪽 정렬 |

## 4. 화면 단위(AutoScaleDimensions) 주의

Designer 에 적는 숫자는 화면의 `AutoScaleDimensions` 단위다. 실행 크기(96dpi, 이 PC 기준)는 단위에 따라 다르다. 2026-10-16 시험 프로그램과 실제 화면 실측으로 확인했다.

| 화면 단위 / 글꼴 | 실행 배율 | 실행 28px 버튼의 Designer 값 | 해당 화면 |
| --- | --- | --- | --- |
| 7x12 / 굴림 9 (글꼴 지정 없음) | 1 | 높이 28 | frmEtResultView / frmGdsKlarfSourceFind / GdsDieAnalysisForm / MenuEditorForm / IconEditForm |
| 10x18 / 굴림 9 | 가로 0.7 / 세로 0.667 | 높이 42 (폭은 실행 폭 x 10 / 7) | frmEtParaRegister / frmEtParaSetup / frmEtResultUpload / frmGdsKlarfAnalysis / GdsMapForm / GdsMapViewForm / MapCopyForm |
| 7x15 / 맑은 고딕 9 | 1 | 높이 28 | frmKlarfFileViewer |
| 10x25 / 맑은 고딕 9 | 1 (배율 적용 안 됨, 실측) | 높이 28 | frmKlarfUpload / frmStandardMapSetup / frmStandardMapView |

- 10x18 화면은 150% 화면에서 Designer 로 저장된 것이다. 숫자를 그대로 비교하면 안 된다.
- 아이콘(16px)은 배율과 상관없이 16px 로 그려진다.
- 새 화면은 100%(96dpi) 화면에서 Designer 작업해 `7x12`(굴림) 단위로 만든다. 어느 단위든 아래 검사로 실행 크기를 확인한다.

## 5. 새 화면을 만들 때 순서

1. 버튼마다 3절에서 KEY 를 고른다. 공통 기능이면 반드시 공통 KEY 를 쓴다.
2. 화면 resx 에 아이콘을 넣는다. 둘 중 하나로 한다.
   - VS Designer: 버튼 Image -> 로컬 리소스 -> `BTN_<KEY>.png` 가져오기.
   - 명령: `python DMS\99_Resource\ByModule\POC\Button\button_icons.py set <화면.resx> btnSearch=SEARCH btnSave=SAVE ...`
     - resx 가 없으면 새로 만든다. 이 경우 csproj 에 `EmbeddedResource` + `DependentUpon` 을 넣는다.
     - Designer 에는 `ComponentResourceManager resources` 줄과 `Image` / `TextImageRelation` 줄을 넣는다.
3. 2절 기준대로 크기 / 위치를 맞춘다. 높이 28, 막대 40, 저장은 오른쪽 끝.
4. 검사를 실행한다. 새 화면은 `Verify-PocButtonLayout.ps1` 의 `$forms` 목록에 한 줄 추가한다.

```powershell
powershell -NoProfile -STA -ExecutionPolicy Bypass -File DMS\02_DMS\DACrux.SEMDMS.ENGUI\Verification\Verify-PocButtonLayout.ps1
```

- 결과 파일: `%TEMP%\chippac\buttonlayout\report.md`. 마지막 줄이 `POC_BUTTON_LAYOUT=PASS` 여야 한다.
- 화면 그림: `images\<화면>.png`
- 검사 항목:
  - 보이는 버튼 / 숨김 버튼마다 16x16 아이콘이 있고, 목록에 있는 그림인지
  - ImageBeforeText 인지
  - 실행 높이가 28 ± 2 인지
  - 글자 + 아이콘이 폭 안에 들어가는지
  - 같은 부모 안에서 보이는 컨트롤끼리 겹치거나 부모 밖으로 나가지 않는지
- 아이콘 점검만 할 때: `python button_icons.py audit <폴더 또는 Designer.cs>`. 버튼마다 KEY / 크기 / 아이콘 없음을 표로 보여 준다.
