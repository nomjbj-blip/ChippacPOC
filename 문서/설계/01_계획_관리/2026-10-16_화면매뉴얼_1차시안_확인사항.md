## 2. 화면별 확인 사항

| 화면 | 확인 사항 |
| --- | --- |
| GDS Map Setup | Layer 체크는 더블클릭으로만 바뀜(GDS Map View 의 Layer 탭은 한 번 클릭). AREF 가 있는 GDS 는 [DB 저장]이 막힘. 기능 문서에 적힌 Layer 우클릭 색 변경은 현재 소스에 없음 |
| GDS Map View | Label 검색, [Output 지정], 격자 크기 입력은 화면에서 숨김. 유사 묶음 흐름은 별도 장으로 뺄지 결정 필요. [Map ▾] → Map 삭제는 되돌릴 수 없음 |
| File Map Setup | Die 편집(보기 / 제거 / 복원), [검사 Die 외 제거], [Wafer 밖 제거], [KLARF 값으로], [저장 Map 열기]가 숨김 상태이고 숨긴 경위 기록이 없음. 상태 줄 문구 `원형 생성 전` 과 단추 이름 [다시 그리기]가 다름 |
| Wafer Map View | 목록은 Factory 구분 없이 삭제 표시되지 않은 Map 전체(기존 Map Define 화면 Map 포함) |
| E-Test Para Register | 찾기 칸, 신규만 체크는 숨김. 이름 충돌, 단위 다름 행의 해결 방법 안내 여부 |
| E-Test Para Setup | 메뉴 툴팁에 `Spec 표 붙여넣기 / 삭제` 가 남아 있으나 두 단추는 숨김. 색 표시(노랑 / 빨강 / 주황 / 회색) 범례를 넣을지 결정 필요 |
| KLARF File Upload | 화면 제목(폼 Text)은 `KLARF Upload` 로 메뉴 이름과 다름. 등록된 Wafer 확인 창의 예 / 아니요 / 취소 의미 표기 방식 |
| E-Test Result Upload | `등록 Parameter 없음` 오류 문구가 `E-Test Para 설정에서 먼저 등록` 으로 나옴(실제 등록 화면은 E-Test Para 등록) |
| E-Test Result View | 캡처 시점 로컬 DB 에 저장된 E-Test 결과 파일이 없어 빈 목록으로 찍힘. 파일 재업로드 뒤 다시 캡처 필요 |
| GDS-KLARF Analysis | [준비] 탭 Step 목록 규칙이 반영 중(소스 수정 시각이 배포 DLL 보다 늦음). 반영, 배포 뒤 다시 캡처 필요. Wafer Key 규칙은 잠정 |
| Defect Map Viewer | 2026-10-16 소스 변경(Reclassify / RD 탭 숨김 등)이 배포된 뒤 화면과 같은지 확인 필요 |
| Chart Analysis / Defect Image Gallery | RECLASSIFY, Remove Image 탭은 DB 의 Class 변경, 이미지 삭제 기능임. 매뉴얼 포함 여부 결정 필요 |
| TEST Map View | Option 영역 [Map Draw](그림 단추)와 Para Item 탭 [Map Draw] 이름이 같음 |
| Wafer Cum / Bin Report | 선택 Wafer 의 TEST AREA 가 메뉴 지정 목록(PRELASER, MULTIPROBE, POSTLASER, AVI, TSVET, COWET, FT) 밖이면 메시지 없이 빈 화면 |
| Yield Report | Scatter / Box Plot 은 WAFER_ID 가 `Lot ID-번호` 형식일 때만 값이 들어감 |
| Param Analysis | 메뉴명은 Param Analysis 지만 맵 없이 표, 차트 화면임 |
