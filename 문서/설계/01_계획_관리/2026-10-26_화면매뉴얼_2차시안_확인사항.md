## 2. 화면별 확인 사항

| 화면 | 확인 사항 |
| --- | --- |
| GDS Map Setup | [Load from File] → [파일 열기], [Redraw] 삭제, [Cell] 콤보 추가. Layer 는 체크 박스로만 바뀜. 파일을 열면 Layer 전체 체크 상태 |
| GDS Map View | [도형 추가] / [도형 제외], [Chain 저장] 으로 이름 바뀜. Chain 탭 [전체 체크] 추가. Label 검색, 유사 묶음 흐름은 1장에 넣지 않음. GDS Map View U8 은 메뉴 숨김이라 제외 |
| Wafer Map Setup / View | 설정 라벨에서 단위가 빠져 화면에서 단위를 알 수 없음. View 의 [Map 정보] 탭 숨김 |
| E-Test Para Register | [Device 삭제] 추가(되돌릴 수 없음). 메시지 열 숨김으로 오류 사유는 행 색으로만 보임 |
| E-Test Para Setup | 표 열 머리글(GDS Chain, Enable, 사용)이 필터 라벨과 같아 번호는 표 열에 직접 지정함 |
| E-Test Bin Setup | 툴팁의 "업로드 파일 Bin 분포"(Die / Pass / Fail 열)가 숨김 |
| E-Test Result Upload | 상태 / 메시지 줄 숨김, 상태는 정보 표 제목 끝, 사유는 아래 상태 줄. "등록 Parameter 없음" 문구가 옛 화면 이름을 가리킴 |
| KLARF File Upload | 분류 기준 콤보 삭제(Class 는 파일 값 그대로). Map 없음 안내 문구가 옛 이름(File Map Setup) |
| GDS-KLARF-ET Correlation | Wafer 를 받으면 바로 1차 분석. E-Test 는 상세보기에서만 보이고 연결된 파일 이름은 화면에 없음 |
| Defect Type Define | 오른쪽 속성 칸 버튼(Insert / Edit / Save / Delete)은 Framework DLL 안이라 소스로 확정 못 함. 목록 머리글이 DB 열 이름 그대로 |
| DMSearch | 결과 표가 검사 1건 1행 목록으로 고정(StepSummary, Value Type 숨김) |
| Defect Map Viewer | ImageList 탭이 새 이미지 카드로 바뀜 |
| TEST Analysis 7개 | 10-16 이후 변경 없음. 캡처는 TEST Wafer 1장(RH-HS2615-02) 기준이라 Gallery, Report 는 Wafer 1장만 보임 |

## 3. 캡처 번호를 붙이지 못한 항목(10개)

우클릭 메뉴나 접힌 패널 안 항목: Defect Map Viewer(Defect Select), TEST Map View(Section Filter, Para Limit, Para Analysis), Bin Map Gallery(맵 클릭), Wafer Bin Report(Size Reset, Chart Config), Param Analysis(Trend / Sigma / Spec Limit, COUNT ~ LSL, 차트 우클릭)
