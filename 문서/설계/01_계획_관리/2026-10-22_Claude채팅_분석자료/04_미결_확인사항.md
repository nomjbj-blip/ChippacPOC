# 미결 / 확인 사항 (2026-10-22 기준)

## 고객 확인 대기

| 항목 | 내용 |
|---|---|
| Wafer 매칭 | KLARF Lot `PFIC_U9-FS2635_C4Bump` + WaferID 숫자 ↔ E-Test `U9-HS2635-01` (FS / HS 표기 차이). U8 은 KLARF `PFIC_U8-NPI_RDL` / WaferID `XD093.01` ↔ E-Test `U8-NPI-01` |
| Offset / 허용오차 기본값 | 파일마다 KLARF 중심 좌표가 다름. 고객 논의 기준은 "TSV Pitch 를 반지름으로 하는 영역" -> 사각형으로 구현 |
| U8 Define rule | Connectivity / PowerShort / PlaneResistance 판정 기준 (파일 Limit 사용 여부, PlaneResistance Limit N/A) |
| U8 이름 연결 | 수정한 E-Test 파일 재송부 대기. E-Test Net 이름을 GDS Chain 이름으로 바꿔 연결 |
| 나머지 Chain 계열 | U9 C4DC / ASICDC / HBMDC / PIC 의 이름 규칙과 Spec |
| Defect 이미지 | FTP 개방 후 연구소가 업로드 |
| 네트워크 | 연구소 사용 망(고정 IP 대역) 정보 -> IT팀 방화벽 개방 |
| YMS 범위 | 파트장 요청 배경, POC 에 어디까지 보일지 |

## 개발 남은 일

- 연관 분석 화면에 E-Test 결과 연결 ("비교 불가" -> 실제 Fail 매칭)
- Wafer 단위 화면, Defect 크기 / 마진 / Offset 설정
- 연관 없는 목록(Defect 만 있음 / Fail 만 있음) 확인
- U8 대량 Net(약 27,000) 처리 속도 / 메모리
- 비 Silterra Die 분석 제외
- 고객 히트맵(10/14)과 Die 별 Defect 수 / Fail Chain 수 대조로 좌표 검증

## 분석할 때 주의

- U9 Spec 의 RES 상한 715 Ω, 측정기 상한값 719 가 나오면 Fail.
- LKG Fail 은 두 Chain 모두 후보.
- U8 비 Silterra 50 Die 는 Connectivity 전부 Fail 이므로 통계에서 뺀다.
- KLARF Pitch 와 고객 Die 크기는 몇 µm 다르다 (Scribe 포함 여부).
