### 3.3 Factory

- 화면에 Factory 선택 / 입력은 두지 않는다 (POC 규칙: 로그인 `GlobalVariable.Factory` 사용).
- 다만 `CREATE_MAP` 이 FACTORY 를 넣지 않으므로 목록에서 Factory 로 거르면 생성 화면으로 만든 Map 이 빠질 수 있다. 1차는 **거르지 않는다** (기존 `GET_MAPDEF_ALL` 도 Factory 조건 없음). DB 기본값을 확인한 뒤 필요하면 바꾼다.

## 4. Map 그리기 방식 (저장 번호 -> LeftBottom)

생성 화면과 같은 이유(CLAUDE-063)로, 조회 화면도 Map 컨트롤에는 **LeftBottom 번호**로 넣고 저장 방향 번호는 표시에만 쓴다. 그래야 LeftTop Map 에서도 마우스 위치 Die 가 맞는다.

1. 격자 = 저장값 `DIE_INDEX_MIN/MAX_X/Y` (생성 화면이 번호를 뒤집을 때 쓴 범위와 같다).
2. Die 번호: `LB = KlarfMapRule.FromDirection(저장 번호, XY_DIRECTION, 격자)` (Right 계열은 X, Top 계열은 Y 를 `Min + Max - 값` 으로 뒤집음).
3. 원점 인덱스: 저장값은 `MapOriginIndex(방향)` 결과이므로 거꾸로 푼다 (`sumX = MinX + MaxX`, `sumY = MinY + MaxY`, 저장값 `(ox, oy)`).

   | 저장 XY 방향 | LeftBottom 원점 인덱스 |
   | --- | --- |
   | LeftBottom | (ox, oy) |
   | LeftTop | (ox + 1, sumY - oy) |
   | RightTop | (sumX - ox, sumY - oy) |
   | RightBottom | (sumX - ox, oy) |

   이 식은 `KlarfMapRule` 주석의 `AddDie` 위치식(방향별 원점 모서리)을 그대로 거꾸로 푼 것이라, 생성 화면이 아닌 기존 Map Define 으로 만든 Map 에도 같은 위치가 나온다 (8절에서 검사).
4. 나머지 설정은 생성 화면 `GenerateCircleMap` 과 같은 순서: `ViewAngle 0 / AngleOffSet 0 / WaferSize (WAFER_SIZE µm 저장값 그대로, 구현 시 정정) / EdgeSize (mm x 1000 = µm, 0 ~ 5 mm 밖이면 0) / NotchType / NotchAngle / XYDirect = LeftBottom / DieSize / OriginIndex / Origin µm / DieMin·Max / FirstDie / Fit -> Redraw -> DieClear -> AddDie(LB 번호, USECODE)`.
5. `DieCalculation(true)` 는 쓰지 않는다 (AddDie 와 한 칸 다름, F05 기록).

참고: 기존 `frmSetupMap.DrawLoadingMap` 은 EDGE_SIZE(mm) 를 Map 컨트롤에 그대로 넣는다 (µm 컨트롤에 2.5 ~ 5 가 들어감). 조회 화면은 생성 화면 기준(µm)으로 1000 을 곱해 Edge 선이 생성 화면과 같게 보이게 한다. Die 위치 / USECODE 에는 영향 없다.

계산은 화면 코드와 분리한 `StoredMapLayout` (신규, 7절) 에 둔다. 화면 없이 Smoke 에서 같은 계산을 검사하기 위함이다.

## 6. 데이터 확인 항목

"Data 가 잘 들어갔는지" 를 화면에서 바로 판단할 수 있도록, 저장된 정의값과 Die 행을 비교한다. 생성 화면 저장 규칙(1절)에 맞으면 모두 "일치" 가 나와야 한다.

| # | 항목 | 비교 | 결과 |
| --- | --- | --- | --- |
| 1 | Die 행 | TQP_USEMAP 행 수 > 0 | 일치 / 다름 (0행 = 정의만 저장된 부분 실패 의심) |
| 2 | Net Die | 저장 NETDIE = USECODE 1 행 수 | 일치 / 다름 |
| 3 | Die 범위 | 저장 DIE_INDEX_MIN/MAX X·Y = Die 행 번호 최소 / 최대 | 일치 / 다름 |
| 4 | 중복 Die | 같은 (X, Y) 행 없음 | 일치 / 다름 (중복 목록 표시) |
| 5 | 격자 채움 | 행 수 = (MaxX - MinX + 1) x (MaxY - MinY + 1) | 일치 / 참고 (생성 화면은 격자 전체 저장. Map Define 으로 만든 Map 은 일부만 있을 수 있음) |
| 6 | USECODE 구성 | 1 / -1 / 기타 값별 행 수 | 참고 (기타가 있으면 값 표시) |
| 7 | Wafer 밖 사용 Die | 사용(1) Die 중 Wafer 반지름 - Edge 밖인 수 (`StandardMapEditMap.IsInsideWafer`, 생성 화면과 같은 판정) | 0 = 일치 / 1 이상 = 참고 (작업자가 일부러 살렸을 수 있음) |
| 8 | Edge 단위 | 0 ≤ EDGE_SIZE ≤ 5 (mm, 생성 화면 기본 Edge 0) | 일치 / 다름 (범위 밖이면 Map Define 에서 불러올 때 오류, 2026-10-06 기록). 범위 밖이면 Map 은 Edge 0 으로 그림 (Edge 가 반지름보다 크면 Map 컨트롤이 예외로 멈춤, 구현 시 확인) |
| 9 | XY 방향 | XY_DIRECTION 이 0 ~ 3 (`XYDirection` 값) | 일치 / 다름 (다르면 그리기 중단) |
| 10 | Wafer 크기 단위 (구현 시 추가) | WAFER_SIZE ≥ 1,000 (µm) | 일치 / 다름 (mm 로 저장되면 Map 이 아주 작게 그려짐) |
| 11 | Die 크기 단위 (구현 시 추가) | CHIP_SIZE_X / Y ≥ 10 (µm) | 일치 / 다름 (로컬 DB PX52 = 3.34 x 3.12: Die 가 1 픽셀보다 작아 마우스로 잡을 수 없음) |
