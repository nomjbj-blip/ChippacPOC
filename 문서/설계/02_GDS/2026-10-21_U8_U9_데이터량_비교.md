# U8 / U9 GDS 데이터량 비교 (고객 설명용, 2026-10-21)

## 한 줄 요약

**U8 과 U9 는 Die 크기가 같지만, U9 는 "시험용 사슬(Daisy Chain) 몇 개", U8 은 "제품 전체 배선(Functional Net)"을 담고 있다.**
그래서 같은 면적에 도형 3배, 좌표 6.5배, Label 9배가 들어 있고, 분석 단위(Chain / Net)는 15개 남짓에서 2만 7천여 개로 늘어난다.

## 1. 두 Device 의 성격

| 구분 | U9 (OMM Hybrid / TCB) | U8 (PFIC) |
| --- | --- | --- |
| 설계 목적 | TSV / C4 / HBM 연결을 확인하는 **시험 구조(Test Vehicle)** | **실제 제품 Package** 의 전원 / 신호 배선 |
| 연결 구조 | 긴 사슬(Daisy Chain) 몇 개가 Die 전체를 지나감 | Bump 마다 독립된 Net 이 수만 개 |
| 측정 | RES / LKG | Connectivity / PowerShort / PlaneResistance |
| 분석 단위 | Chain 15 ~ 19개, Chain 1개에 도형 3,300 ~ 4,400개 | Net(Chain) 약 27,000개, Net 1개에 도형 10개 |

## 2. 숫자로 보는 차이 (같은 크기 Die, 전체 도면 기준)

| 항목 | U9 | U8 | U8 / U9 |
| --- | ---: | ---: | ---: |
| Die 크기 | 23,760 x 29,985 µm | 23,693 x 29,775 µm | 같음 |
| GDS 파일 크기 | 87 MB | 346 MB | 4.0배 |
| 파일 구조 | Cell 1개(평면) | Cell 18개(반복 Cell 참조 116,397회) | - |
| Layer | 9개 | 17개 | 1.9배 |
| 도형 수 | 605,080 | 1,817,538 | **3.0배** |
| 좌표 점 수 | 829만 | 5,415만 | **6.5배** |
| 도형 1개당 평균 점 | 13.7 | 29.8 | 2.2배 |
| Label(문자) | 30,992 | 274,162 | **8.8배** |
| 좌표 데이터 용량 | 약 133 MB | 약 866 MB | 6.5배 |

## 3. 왜 이렇게 커지는가

1. **분석 단위가 다르다.**
   U9 는 사슬 하나가 Die 를 길게 지나가므로 Chain 수가 적다. U8 은 Bump 마다 전원 / 신호 Net 이 따로 있어 Net 수가 수만 개다.
2. **Bump 를 원으로 그린다.**
   U8 의 C4 / TSV Bump 는 점 33 ~ 65개짜리 원(다각형)이다. U9 는 대부분 선(PATH)과 사각형이라, 같은 도형 수라도 U8 좌표가 훨씬 많다.
3. **Label 이 Bump 마다 붙어 있다.**
   U8 은 Bump 마다 핀 번호(예 `C4_26814`, `TSV_26826`)와 Net 이름(예 `VSS`, `DDR0_PAD_CAL_0`)이 있다. 같은 Label 이 제품 Cell 과 뒷면 Cell 에 2벌 들어 있다.
4. **Layer 가 많다.**
   U8 은 앞면 / 뒷면 RDL, TSV, C4, Package 를 모두 담아 KLayout 기준 17개 Layer(번호 / DataType)다.
5. **같은 내용이 겹쳐 배치된 곳이 있다.**
   예: `TOP` 의 Package C4 가 같은 자리에 2번 배치되어 있다. 시스템은 위치와 내용까지 같은 도형 68,001개를 한 번만 그린다. 화면 모양은 KLayout 과 같다.

## 4. 시스템에 미치는 영향 (로컬 PC 측정)

| 항목 | U9 | U8 |
| --- | ---: | ---: |
| GDS 파일 읽기 | 약 5.5초 | 약 20초 |
| 화면 구성(펼치기 + 그리기 준비) | 2.7초 | 18.1초 |
| 화면 메모리 | 약 0.6 GB | 약 2.8 GB |
| 전체 화면 다시 그리기(이동 / 확대 1회) | 0.03초 | 0.5 ~ 1초 |
| DB 에서 전체 Layer 불러오기 | 약 17초 | 약 102초 |

- 개선 전 시스템은 U8 제품 전체를 화면에 올릴 때 메모리 한도를 넘어 열리지 않았다. 그리기 구조를 바꿔 지금은 18초에 열린다.
- U8 Net 자동 추출(예시 Net 과 같은 형태 찾기)은 27,341개를 약 34초에 찾았다.

## 5. 시스템 대응과 운영 방법

| 구분 | 내용 |
| --- | --- |
| 완료 | KLayout 처럼 최상위 Cell 을 자동으로 고른다(U8 파일은 하위 Cell 이 먼저 기록되어 있음). |
| 완료 | 대용량 그리기 구조 개선 -> U8 제품 전체 표시 가능. |
| 완료 | Layer 를 KLayout 과 같은 번호 / DataType(예 `18/0`, `18/3`, `18/4`)으로 나눔. |
| 운영 | **분석에 필요한 Layer 만 등록한다.** 현재 U8 은 4개 Layer(`50/3`, `850/0`, `860/0`, `900/0`)만 등록: 도형 329,114개(전체의 18%), 좌표 1,623만(30%). U9 도 3개 Layer 만 등록해 도형 204,898개다. |
| 남은 과제(선택) | 전체 화면 다시 그리기 0.5 ~ 1초 -> 멀리서 볼 때 원을 단순하게 그리는 방법으로 줄일 수 있다. |

### 등록된 데이터 비교 (분석용 Layer 만)

| 항목 | U9 | U8 |
| --- | ---: | ---: |
| 등록 Layer | 3개 (`3/0`, `5/0`, Label `775/237`) | 4개 (`50/3`, `850/0`, `860/0`, `900/0`) |
| 도형 | 204,898 | 329,114 |
| 좌표 점 | 626만 | 1,623만 |
| Chain(Net) | 1 ~ 19개 | 27,342개 |
| Chain 에 속한 도형 합계 | 3,700 ~ 66,500 | 273,420 |

## 6. 고객 확인 요청 (필요 시)

- U8 분석에 꼭 필요한 Layer 목록(지금 4개로 충분한지). Layer 가 늘수록 저장 / 조회 시간이 늘어난다.
- Layer 이름(예 `18/3` = 핀 번호 Label)을 표시하려면 고객 KLayout Layer 설정 파일(`.lyp`)이 있으면 받는다. GDS 파일에는 Layer 이름이 없다.
