# U8 같은 형태 Chain 자동 추출 설계 (검증 결과 포함)

작성: 2026-10-20 / 작업 ID: CLAUDE-165 / 상태: 알고리즘 검증 완료(Probe) / 제품 기능 미구현 - 범위 결정 대기

## 1. 요청

- U8 은 화면처럼 같은 형태의 Chain 이 아주 많다. 사용자가 Input 지정 + [후보 경로 찾기]로 만든 Chain `TSV_21063`(도형 10개)과 같은 형태 / 크기의 Chain 을 자동으로 찾는 알고리즘을 고민한다.
- 1단계(이 문서): 소스 변경 없이 Probe 로 U8 전체에 돌려 일치 개수 / 시간을 실측한다.

## 3. 기존 기능과의 차이

| 기능 | 하는 일 | 이 요청에 |
| --- | --- | --- |
| [후보 경로 찾기] (`ChainCandidateTracer`) | Input 1개에서 선택 Layer 도형의 실제 접촉을 따라 BFS. Output 없으면 닿는 연결 덩어리 전체 | Chain 1개씩. 2.7만 번 반복 불가 |
| [예시 묶음 지정] + [유사 묶음 찾기] (`ChainSimilarGroupFinder`) | **지금 Chain 안의 도형**에서 예시 묶음의 평행 이동 반복을 찾음(긴 Daisy Chain 의 링크별 구조 제외용) | 도면 전체에서 새 Chain 을 만들지 않음 |

## 4. 알고리즘 (A안: 연결 덩어리 일괄 + 예시 Chain 비교)

1. **기준 읽기**: 예시 Chain 의 탐색 Layer(850/0, 860/0, 900/0), 연결 판정(Layer 규칙 끔 = 화면 기본), 예시 Label.
2. **공간 격자**: 탐색 Layer 도형 전체(274,280개)를 100 µm 격자에 넣는다(도형이 걸친 모든 칸에 등록).
3. **연결 덩어리**: 같은 칸의 두 도형이 외곽 상자로 닿고 `ChainGeometryOverlap.Intersects`(화면 [후보 경로 찾기]와 같은 판정)가 참이면 Union-Find 로 묶는다. 이미 같은 덩어리면 형상 검사를 건너뛴다.
4. **이름**: Label(50/3 `TSV_*`, 같은 자리 2벌은 하나)이 들어 있는 도형(`ChainGeometryOverlap.ContainsPoint`)의 덩어리에 Label 이름을 붙인다.
5. **형태 비교**: 덩어리마다 도형 구성(Layer / 종류 / 꼭짓점 수 / 크기 5 µm 묶음)이 예시와 같은지, 같으면 가장 드문 도형(연결 도형)을 기준점으로 모든 도형의 상대 위치가 0.5 µm 안에서 맞는지 본다. 8 방향(회전 0/90/180/270 x 좌우 대칭)까지 비교한다.
6. **분류**: 일치 / 회전·대칭 일치 / 구성 같음·배치 다름 / 구성 다름(도형 더 많음 = 이웃과 붙음 등 / 더 적음).

## 6. 제품 기능으로 만들 때 (안)

- **화면**: GDS Map 조회 Chain 탭에 [같은 형태 찾기]. 지금 고른 Chain 을 예시로 계산(백그라운드) -> 결과 창(일치 n / 검토 m, 검토 목록은 위치로 이동) -> 범위 선택 -> [생성].
- **Chain 생성 규칙**: 이름 = Label(`TSV_nnnnn`), Input = Label 이 들어 있는 도형(예시의 Input Layer), 탐색 Layer / 규칙 / 격자 = 예시와 같음, 포함 도형 = 연결 덩어리(예시와 같은 방식이라 2벌 도형도 그대로).
- **일괄 저장 서비스(신규)**: 지금 Chain 저장은 1개당 서버 호출 3번(시작 / 포함 도형 / 확정) -> 2.7만 개면 약 8만 번. Chain 여러 개를 표 단위로 받아 CHAIN / VER / LAYER / MEMBER 를 1만 행씩 `InsertExecuteMultiple`, CHAIN_SEQ 는 한 번에 여러 개 채번. 규모: Chain 27,341 / 탐색 Layer 82,023 / 포함 도형 273,410 행.
- **계산 시간**: 연결 22.5초는 64점 원끼리 형상 검사 비용. 화면 기능에서는 진행 표시 + 취소, 필요하면 원 / 사각 전용 빠른 판정을 검토.
