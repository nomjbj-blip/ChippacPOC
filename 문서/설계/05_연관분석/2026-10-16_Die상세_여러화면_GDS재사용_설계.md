## 5. 권장 설계 (B + C)

### 5.1 창 구성

- 상세보기 창(호스트 `frmGdsDieAnalysis`)은 Die 마다 하나. 탭 제목 = "상세보기 (X, Y)"(지금과 같음).
- 같은 Die 를 다시 열면 그 창을 앞으로 가져온다(D2). E-Test Fail 역추적으로 열었으면 그 창의 역추적 Chain 만 바꾼다.
- 다른 Die 를 열면 새 창을 만든다. 기존 창은 그대로 남는다.
- 각 창은 자기 값을 가진다: AnalyzeDie 결과(DataSet), Die (X, Y), 역추적 Chain, 보기 상태(확대 범위 / Defect 범위 콤보 / 선택 Defect / Chain 행 / Chain 표시 체크 / 탭 위치).

### 5.2 공유 상세 화면 (도면 하나)

- `GdsDieAnalysisForm`(도면 + 표) 하나를 모든 상세보기 창이 같이 쓴다. 호스트의 static 으로 둔다(GdsMap EXE 는 `Assembly.LoadFrom` 으로 한 번만 읽힘).
- 상세보기 창이 활성화되면(MDI 탭 전환 / 새 창 표시):
  1) 지금 가진 창의 보기 상태를 그 창에 저장한다.
  2) 공유 화면을 새 창 패널로 옮긴다(`Controls.Remove` -> `Controls.Add`, 핸들 유지).
  3) 새 창의 결과로 `ShowDie` -> 도면 키가 같으므로 도면은 다시 읽지 않고 Defect 표시 / Chain 목록 / Defect 목록만 다시 만든다(지금 `ShowCurrent` 경로).
  4) 새 창의 보기 상태를 복원한다(처음이면 지금처럼 Defect 범위로 확대).
- 공유 화면이 없는 창(탭 그룹을 나눠 같이 보이는 경우)은 패널에 "다른 상세보기에서 표시 중 - 이 창을 누르면 여기 표시" 안내를 둔다(D6).
- 분석 조건이 바뀌어 Device / 보기 기준이 달라진 창이면 도면 키가 달라 그때 한 번 다시 읽는다(지금 키 규칙 그대로).

### 5.3 미리 읽기 ([분석] 때)

- 화면 A [분석]이 끝나면 GdsMap 공유 도면 데이터 캐시에 그 Device 의 도면 데이터 + Chain Member 를 백그라운드로 읽는다. 키 = Factory | Device | 저장 기준 | 배경 여부 | Chain 최종 저장 시각(`ANL_INFO.CHAIN_LAST_SAVED`).
- 상세 화면이 도면을 만들 때 캐시에 같은 키가 있으면 DB 를 부르지 않는다. 읽는 중이면 그 결과를 기다린다(두 번 읽지 않음).
- 화면 A(ENGUI, .NET 4.0) 는 GdsMap(4.8) 을 직접 참조하지 않으므로 호스트 static 함수(리플렉션)로 부른다(지금 `ShowDie` 와 같은 방식).
- 도면 만들기(약 4초)까지 미리 할지는 D3. 권장은 데이터만(화면 멈춤 없음).
- 캐시는 Device 1개만 둔다(다른 Device 를 분석하면 바꿈). Chain 저장 시각이 바뀌면 버리고 다시 읽는다.
- 캐시는 보기 기준으로 맞춘(반전한) 목록 하나만 둔다. 도면이 그 좌표 배열을 같이 쓰므로 도면을 만든 뒤 캐시가 더 차지하는 메모리는 거의 없다. 반전 전 원본은 반전 뒤 버린다(두 벌이면 약 120 MB 더).

### 5.4 닫기

- 공유 화면을 가진 창을 닫으면 공유 화면을 떼어(Dispose 하지 않음) 다른 열린 상세보기 창으로 넘기거나 숨겨 둔다.
- 상세보기가 모두 닫힌 뒤 공유 화면 / 캐시를 둘지는 D4. 권장: 화면 A 가 열려 있는 동안 두고(다시 열면 바로), 화면 A 를 닫거나 다른 Device 를 분석하면 버린다(메모리 반환).

### 5.5 처리 흐름

```text
[분석] 완료 -> (백그라운드) 도면 데이터 + Chain Member 캐시 채우기
Die 더블클릭 (X, Y)
  -> 같은 (X, Y) 창 있음: 그 창 활성화 (역추적 Chain 만 바꿈)
  -> 없음: AnalyzeDie -> 새 상세보기 창 -> 활성화
상세보기 창 활성화
  -> 공유 화면을 이 창으로 옮김 -> ShowDie(이 창 결과) -> 도면 키 같음: 표시만 / 다름: 캐시 또는 DB 로 한 번 읽기
  -> 이 창 보기 상태 복원
```
